Variables in JavaScript

What is a Variable?
A variable is a container used to store data values in JavaScript. It allows you to reuse and change data in your program.

There are 3 variables

  1. var
  2. let
  3. const
var (Old Way)

var is function-scoped, can be re-declared and updated.

We can assign the list of variable

Example

var age,dateOfBirth,sex

var name = "Rahul";
let (Modern Way)
let is block-scoped. You can update it but cannot re-declare it. 
let age = 20;
const (Constant)
const is used for fixed values and cannot be changed. 
const pi = 3.14;

Data Types in JavaScript

What are Data Types?
Data types define what type of value a variable can store.

Primitive Data Types

String
Used for text values. assigned within the Double quotes 
let name = "Amit";
Number
Used for numeric values. 
let age = 25;
Boolean
True or false values. 
let isStudent = true;
Undefined
Variable declared but not assigned. 
let x;
Null
Represents empty value. 
let data = null;
BigInt
Used for very large numbers. 
let big = 12345678901234567890n;
Symbol
Used to create unique values. 
let id = Symbol("id");

Non-Primitive Data Types

Object
Stores data in key-value pairs. 
let person = {
  name: "Rahul",
  age: 21
};
Array
Stores multiple values in one variable. 
let fruits = ["apple", "banana", "mango"];
Function

A set of actions that are grouped or defined together in the block of code to perform sepcific action is called functions. And these functions can be Reusable once defined to avoid duplication of the code.

A reusable block of Code.

          console.log("Hello!");
